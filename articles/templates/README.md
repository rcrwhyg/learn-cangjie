# 文章模板使用指南

> 本目录包含学习文章的统一内容模板，用于保证文章结构的一致性

## 模板列表

### 1. 入门教程模板
**文件**: `01-variables-and-types-template.md`

**适用场景**: 基础语法、概念讲解、入门教程

**特点**:
- 结构清晰，循序渐进
- 包含前置知识说明
- 提供多种语言对比
- 包含练习题

## 使用步骤

### 1. 选择模板
根据文章类型选择合适的模板

### 2. 复制模板
```bash
# 复制模板到草稿目录
cp articles/templates/01-variables-and-types-template.md articles/drafts/02-operators.md
```

### 3. 替换占位符
- `[文章标题]` → 实际文章标题
- `[摘要]` → 实际摘要内容
- `[核心章节]` → 实际章节标题和内容
- `[代码示例]` → 实际代码示例

### 4. 填充内容
- 按照模板结构填充具体内容
- 确保代码示例完整可运行
- 添加必要的注释和说明

### 5. 格式调整
- 检查Markdown格式
- 调整代码块语法高亮
- 确保链接有效

### 6. 质量检查
- 技术内容准确性
- 代码示例可运行性
- Markdown 结构规范性
- 语言表达流畅性

## 模板自定义

### 添加新模板
1. 在本目录创建新的模板文件
2. 遵循现有的模板结构
3. 在本README中添加说明
4. 提交到版本控制

### 修改现有模板
1. 评估修改的必要性
2. 与团队讨论修改方案
3. 实施修改
4. 更新相关文档
5. 通知相关人员

## 最佳实践

### 内容组织
- **逻辑清晰**: 按照学习路径组织内容
- **层次分明**: 使用合适的标题层级
- **重点突出**: 使用提示框突出重要内容
- **过渡自然**: 章节之间过渡自然

### 代码示例
- **完整可运行**: 所有代码必须能够直接运行
- **注释详细**: 关键代码有详细注释
- **多种场景**: 提供多种使用场景的示例
- **最佳实践**: 遵循语言最佳实践

### 语言对比
- **对比维度**: 语法、特性、性能、适用场景
- **对比深度**: 深入分析异同
- **迁移帮助**: 提供迁移建议
- **实际案例**: 提供实际迁移案例

## 常见问题

### Q: 如何选择模板？
A: 根据文章类型选择：
- 基础语法、概念讲解 → 入门教程模板
- 高级特性、深入分析 → 进阶特性模板
- 实战项目、案例分析 → 实战项目模板

### Q: 可以修改模板吗？
A: 可以，但需要：
1. 评估修改的必要性
2. 与团队讨论修改方案
3. 实施修改并更新文档
4. 通知相关人员

### Q: 模板更新后，已发布的文章需要更新吗？
A: 不需要，已发布的文章保持原样。新文章使用更新后的模板。
