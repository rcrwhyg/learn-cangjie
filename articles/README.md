# 文章目录约定

本项目每篇文章只维护一份 Markdown 文件，文章撰写、审核和修改都在同一份文件上完成。用户确认内容后，将这份文章交给公众号工具发布，不再通过复制或移动文件区分文章状态。

- `articles/`：文章文件目录。
- `templates/`：文章模板目录，不属于文章内容，也不参与发布或代码示例测试。
