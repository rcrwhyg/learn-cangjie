# 文章目录约定

本目录区分文章的内容状态：

- `drafts/`：草稿目录，存放正在撰写、待审核或需要根据反馈修改的文章。
- `articles/` 根目录：正式文章目录，存放已经完成审核并经用户确认的文章。
- `templates/`：文章模板目录，不属于文章内容，也不参与发布或代码示例测试。

正式文章不等同于已经发布到微信公众号。文章只有在审核完成并获得用户确认后，才从 `drafts/` 移动到 `articles/` 根目录；公众号发布是之后的独立步骤。
