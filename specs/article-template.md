## 模板元素说明

### 标题规范
```markdown
# 一级标题（文章标题）
## 二级标题（主要章节）
### 三级标题（子章节）
#### 四级标题（细节说明）
```

### 摘要规范
- **长度**: 150-200字
- **内容**: 文章核心内容和价值点
- **风格**: 简洁明了，吸引读者
- **位置**: 文章开头，标题之后

### 目录规范
- **适用场景**: 长文章（超过3000字）
- **格式**: 使用Markdown链接
- **更新**: 内容修改后更新目录
- **结构**: 使用数字列表

### 代码示例规范
```cangjie
// 代码示例模板
// 文件名: example.cj

// 导入语句
import std.collection.*

// 主函数
main() {
    // 变量声明
    let message = "Hello, Cangjie!"
    
    // 输出结果
    println(message)
    
    // 函数调用
    let result = add(1, 2)
    println("1 + 2 = ${result}")
}

// 函数定义
func add(a: Int, b: Int): Int {
    return a + b
}
```

## 格式规范

### 文字格式
- **正文字体**: 16px
- **标题字体**: 加粗，18-24px
- **代码字体**: 等宽字体，14px
- **行间距**: 1.75倍
- **字间距**: 0.5px

### 段落格式
- **段落间距**: 1.5em
- **首行缩进**: 2em（可选）
- **对齐方式**: 两端对齐

### 列表格式
```markdown
1. 有序列表项
2. 有序列表项
   - 无序子列表项
   - 无序子列表项

- 无序列表项
- 无序列表项
   1. 有序子列表项
   2. 有序子列表项
```

### 链接格式

正文中的普通链接可以使用 Markdown 超链接。`参考资料`章节必须使用“资料名称：完整 URL”的形式，直接展示链接地址，不能使用 Markdown 超链接，以避免公众号等外部转换工具丢失地址。

```markdown
资料名称：https://example.com/reference
```

### 图片格式
```markdown
![图片说明](图片地址)
```
