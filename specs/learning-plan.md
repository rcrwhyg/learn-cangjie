# 仓颉编程语言学习计划

> 基于仓颉 1.0.5 LTS 官方开发指南和工具使用指南制定。文章编号、主题边界和官方章节覆盖关系以本文为准。

## 版本基线

- **语言版本**: 仓颉 1.0.5 LTS
- **默认后端**: CJNative
- **官方文档**: https://docs.cangjie-lang.cn/docs/1.0.5/toc.html
- **官方文档仓库**: https://gitcode.com/Cangjie/cangjie_docs

文章中的“基线版本”表示本文验证所针对的版本，不等同于永久的最新版本。版本相关表述必须按照 `rules/official-docs.md` 进行核验。

## 学习目标

1. 完整覆盖官方开发指南、工具使用指南中的语言和工具章节。
2. 先掌握可运行的语言基础，再深入类型系统、内存、并发和元编程原理。
3. 每个主题都提供官方语义、边界条件、反例和可运行示例。
4. 通过 Go、Java、Swift、Kotlin、Rust 等语言对比帮助迁移，但不以其他语言经验替代仓颉官方定义。
5. 形成可用于实际项目的仓颉开发、测试、构建、调试和发布能力。

## 文章路线

### 阶段一：语言基础（1-15）

目标：完成从程序结构到基础类型、结构类型和包的完整入门。

1. **仓颉编程语言简介与特性概览**：定位、后端、设计特性和学习路线。
2. **开发环境搭建与 Hello World**：SDK、`cjc`、`cjpm`、IDE 和第一个程序。
3. **变量与数据类型**：`let`、`var`、`const`；整数、浮点、Bool、Rune、String、Unit、Nothing；类型推断和转换。
4. **运算符与表达式**：算术、比较、逻辑、位、区间、赋值、复合赋值和优先级。
5. **控制流语句**：`if`、`match` 基础、`for-in`、`while`、`do-while`、`where`、`break`、`continue`。
6. **函数基础**：函数声明、参数、返回值、函数体类型、默认参数、变长参数和作用域。
7. **struct 结构类型**：定义、实例化、成员、构造器、值类型语义和 `mut` 函数。
8. **class 类类型**：引用类型、成员、构造器、终结器、继承前置知识和属性访问。
9. **接口、属性与子类型**：`interface`、接口实现、`prop`、可见性、子类型关系和多态基础。
10. **enum 枚举类型**：枚举构造器、关联值、递归枚举和代数数据类型。
11. **模式匹配**：常量、绑定、元组、枚举、类型、通配符、模式守卫和穷尽性。
12. **数组、元组与区间**：`Array`、`VArray`、Tuple、`Range` 的声明、访问、解构、边界和遍历。
13. **字符串与字符处理**：String、Rune 字面量、插值、多行/原始字符串、编码和常用操作。
14. **Collection 集合类型**：ArrayList、HashSet、HashMap、Iterable、迭代器和集合算法。
15. **包、模块与程序入口**：包声明、导入、重导出、顶层可见性、模块组织和入口函数。

### 阶段二：核心语言特性（16-26）

目标：掌握函数式特性、泛型、扩展、错误处理、I/O、网络和宏。

16. **函数类型、Lambda 与闭包**：一等函数、Lambda、嵌套函数、闭包和函数调用语法糖。
17. **泛型编程**：泛型函数、类、struct、接口、枚举、类型别名和泛型约束。
18. **扩展机制**：直接扩展、接口扩展、扩展中的访问规则和适用边界。
19. **错误处理与 Option**：异常定义、`try-catch-finally`、运行时异常、Option 和错误传播。
20. **资源管理**：资源生命周期、终结器、作用域清理和避免资源泄漏。
21. **并发模型概述**：仓颉线程/协程模型、任务生命周期、调度和并发安全。
22. **线程与协程使用**：创建、访问、终止、等待、睡眠和任务结果。
23. **同步与并发原语**：锁、同步机制、条件协调、线程间通信和竞态处理。
24. **基础 I/O**：流、节点流、处理流、文件读写和资源关闭。
25. **网络编程**：网络模型、Socket、HTTP、WebSocket 和错误处理。
26. **宏与编译时元编程**：词法宏、Tokens、quote、语法节点、宏包、诊断和调试。

### 阶段三：运行时、标准库、互操作与工具链（27-40）

目标：理解运行时能力，能够使用官方工具完成开发、调试、测试和构建。

27. **反射、注解与动态特性**：运行时类型信息、注解、动态调用和限制。
28. **仓颉-C 互操作**：`foreign`、`@C`、CType、指针、结构体、链接和 unsafe 边界。
29. **仓颉-Python 互操作**：Python 对象映射、调用方式、生命周期和异常处理。
30. **标准库总览与使用方法**：标准库分层、模块导入、API 文档、版本匹配和示例阅读方法。
31. **标准库数据结构**：ArrayList、HashMap、HashSet、Deque、迭代器和集合算法。
32. **标准库基础 I/O 与文本处理**：文件、流、编码、字符串、正则表达式和格式化。
33. **标准库数学、时间与序列化**：数学函数、时间日期、随机数、JSON/编码和错误处理。
34. **标准库网络与系统能力**：Socket、HTTP、WebSocket、进程、环境和平台 API。
35. **cjc 编译器**：编译流程、后端、常用参数、诊断、链接和运行时配置。
36. **cjpm 包管理器**：项目初始化、`cjpm.toml`、依赖、构建、运行和测试。
37. **IDE 与语言服务**：VS Code 插件、补全、诊断、格式化、调试和工程视图。
38. **单元测试与覆盖率**：测试结构、断言、测试运行、调试和覆盖率分析。
39. **代码格式化、静态检查与文档**：`cjfmt`、`cjlint`、`cjdoc`、代码规范和持续集成。
40. **调试、性能、构建与部署工具**：`cjdb`、`cjprof`、构建产物、运行时、打包和发布。

### 阶段四：深入原理（41-47）

目标：从语言使用深入到设计、实现和性能原理。

41. **仓颉类型系统**：静态强类型、类型推断、子类型、类型安全和类型错误诊断。
42. **代数数据类型与模式匹配原理**：struct、enum、Option、匹配编译和穷尽性。
43. **const 函数与常量求值**：const 上下文、const 表达式、const init 和编译期计算。
44. **值类型、引用类型与内存管理**：对象模型、赋值语义、生命周期、GC 和资源边界。
45. **并发模型与内存模型**：调度、同步、可见性、竞态、死锁和并发设计。
46. **性能分析与优化**：编译优化、运行时、GC、I/O、并发和性能工具。
47. **仓颉语言演进与设计实践**：版本变化、设计取舍、兼容性和工程最佳实践。

### 阶段五：实战项目（48-52）

目标：把语言、工具链和生态能力组合到完整项目中。

48. **命令行工具实战**：参数解析、文件 I/O、错误处理、测试和发布。
49. **Web 服务实战**：HTTP API、路由、序列化、数据库和部署。
50. **并发应用实战**：任务拆分、通信、同步、取消和性能分析。
51. **跨语言项目实战**：C/Python 互操作、ABI、资源管理和构建。
52. **综合项目与最佳实践**：项目结构、代码质量、CI、文档、版本和发布复盘。

## 文章写作门禁

每篇文章开始前必须：

1. 在矩阵中确认本篇负责的官方章节和边界。
2. 读取对应版本官方章节全文，记录语法、语义、约束、默认行为和反例。
3. 标出首次覆盖、后续深入和暂未覆盖内容，不能用“后续再说”替代文章编号。
4. 为每个可运行示例建立 `examples/` 规范源，并运行同步检查和本地测试。
5. 逐条访问文章参考资料 URL，并记录到 `docs/reference-link-checks.md`。
6. 官方资料无法获取或语义无法确认时，停止撰写并请求用户提供资料。

## 发布与维护

- 文章在同一份文件上持续修改，不复制“正式稿”或“草稿稿”。
- 用户确认内容后，才进入公众号发布流程。
- 提交前运行 `./tools/test-local.sh`，推送后检查 GitHub Actions。
- Actions 失败必须查看日志、修复根因、重新提交和推送，直到成功。
- 官方版本更新、官方文档变更或用户反馈触发覆盖矩阵复审。

## 小阶段复盘门禁

每完成一个小阶段，必须暂停新增文章，进行一次查漏补缺复盘：

1. 对照官方目录复核当前阶段全部章节，确认没有遗漏、误归类或只写标题未安排正文的主题。
2. 对照覆盖矩阵检查当前阶段已完成内容的事实、示例、参考链接和版本标注。
3. 复核下一个阶段，检查是否存在新发现的官方章节、工具、标准库模块或实践主题需要补充规划。
4. 更新学习计划、覆盖矩阵、状态文档和问题记录，并与用户确认后再进入下一阶段。
5. 如果复盘发现重大遗漏，优先调整计划，不继续批量撰写后续文章。
