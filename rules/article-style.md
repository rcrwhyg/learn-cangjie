# 文章风格规范

> 本文档定义了微信公众号文章的排版风格和写作规范

## 整体风格

### 设计理念
- **简约精致**: 避免复杂花哨的设计
- **阅读友好**: 文字大小、行间距、字间距合理
- **专业感**: 体现技术文章的专业性
- **一致性**: 所有文章保持统一的风格

### 色彩方案
- **主色调**: 深灰色 (#333333) 用于正文
- **强调色**: 蓝色 (#1890ff) 用于链接和重点
- **背景色**: 浅灰色 (#fafafa) 用于代码块
- **边框色**: 浅灰色 (#e8e8e8) 用于分割线

## 排版规范

### 字体设置
- **正文字体**: 系统默认字体，16px
- **标题字体**: 加粗，18-24px
- **代码字体**: 等宽字体，14px
- **注释字体**: 斜体，14px

### 间距设置
- **行间距**: 1.75倍行高
- **段间距**: 1.5em
- **字间距**: 0.5px
- **段落首行缩进**: 2em（可选）

### 对齐方式
- **正文**: 两端对齐
- **标题**: 左对齐
- **代码**: 左对齐
- **图片**: 居中对齐

## 文章结构

### 标题层级
```
# 一级标题（文章标题）
## 二级标题（主要章节）
### 三级标题（子章节）
#### 四级标题（细节说明）
```

### 必备元素
1. **文章标题**: 简洁明了，体现核心内容
2. **摘要/导读**: 200字以内的文章概要
3. **正文内容**: 结构清晰，逻辑连贯
4. **代码示例**: 完整可运行，有详细注释
5. **总结**: 核心要点回顾
6. **参考资料**: 官方文档链接
7. **版权声明**: 文章末尾添加版权声明

### 可选元素
1. **目录导航**: 长文章添加目录
2. **提示框**: 重要提示、注意事项
3. **对比表格**: 语言对比分析
4. **流程图**: 复杂流程说明
5. **截图**: 工具使用说明

## 代码规范

### 代码块格式
```cangjie
// 代码示例
main() {
    // 这是一个示例
    println("Hello, Cangjie!")
}
```

### 代码注释
- **关键代码**: 必须添加注释
- **复杂逻辑**: 详细解释原理
- **参数说明**: 解释参数含义
- **返回值**: 说明返回值类型和含义

### 代码高亮
- 使用Markdown代码块语法
- 指定语言类型进行高亮
- 保持代码格式整洁

## 特殊元素

### 提示框
```markdown
> **💡 提示**
> 这里是重要提示信息

> **⚠️ 注意**
> 这里是需要注意的事项

> **❌ 警告**
> 这里是警告信息
```

### 对比表格
```markdown
| 特性 | 仓颉 | Golang | Java |

| 并发模型 | 协程 | goroutine | 线程 |
```

```markdown

```
```

## 图片规范

### 图片尺寸
- **宽度**: 100% 或 最大750px
- **高度**: 根据内容自适应
- **格式**: PNG、JPG、GIF

### 图片位置
- **居中显示**: 所有图片居中
- **添加说明**: 图片下方添加说明文字
- **适当留白**: 图片上下留适当空白

### 图片内容
- **代码截图**: 使用等宽字体，语法高亮
- **流程图**: 清晰易懂，颜色协调
- **对比图**: 突出差异，便于理解

## 链接规范

### 内部链接
- 使用相对路径
- 链接文本要有意义
- 避免"点击这里"等模糊文本

### 外部链接
- 链接到官方文档
- 使用完整URL
- 添加链接说明

## 版权规范

### 版权声明
```
本文原创发布于微信公众号【仓颉编程学习】
转载请注明出处，侵权必究
```

### 引用规范
- 引用官方文档需注明来源
- 引用他人内容需获得授权
- 遵守知识产权相关法律

## 响应式设计

### 移动端适配
- 字体大小适中
- 代码块可横向滚动
- 图片自适应宽度
- 避免过宽的表格

### 平板适配
- 保持良好可读性
- 适当调整布局
- 优化触摸体验

## SEO优化

### 标题优化
- 包含关键词
- 长度适中
- 吸引点击

### 内容优化
- 合理使用关键词
- 结构清晰
- 内容有价值
